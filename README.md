# DBATU Campus Guide

A simple HTML-based website created to provide useful information about Dr. Babasaheb Ambedkar Technological University (DBATU), Lonere.

## About the Project

The DBATU Campus Guide provides information about the university, campus facilities, library, hostel, and other important areas of college life.

## Features

- DBATU campus introduction
- College facilities
- Library information
- Hostel information
- Navigation menu
- Images
- Feedback form
- Simple and user-friendly design

## Technologies Used

- HTML
- Basic CSS

## Project Purpose

This project was created as a beginner web development project to practice HTML concepts such as headings, paragraphs, links, images, tables, forms, navigation, header, main content, and footer.
